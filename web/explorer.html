The gap

Satellites see the surface. Floats feel the depth.

Argo floats measure true temperature profiles, but each float reports roughly every 10 days and the array is sparse. Satellites watch the whole ocean daily, yet only see its top layer.

AquaSphere learns the link between the two.

How it works

From surface signals to a profile

  1. SensorsSea-surface temperature, sea-level anomaly, salinity and wind.
  2. EmbeddingA compact numeric summary of the local surface state.
  3. ProfileTemperature at 15 depths between 0 and 1000 m.
  4. UncertaintyA range around every estimate, checked against floats the model never saw.

⚠️ Why Float-Grouped Splits Are Mandatory: Argo floats drift slowly and sample every 10 days. Naive random splitting places adjacent profiles from the same physical float into both train and test sets. Because subsurface stratification has long autocorrelation times, random splits "memorize" float profiles, artificially underestimating error by 0.471 °C. AquaSphere's evaluations strictly quarantine entire float trajectories to prevent leakage.

Each latent dimension encapsulates orthogonal oceanographic modes: baroclinic Rossby wave phase, mixed layer buoyancy flux, barrier layer salinity stratification, and thermocline depth modulation.

Tier A Neural Architecture

Multi-Sensor Cross-Attention Profile Generator.

1. Surface Observation Encoder:
Multi-modal inputs: [SST, SSS, SLA, Ug, Vg, U10, V10, DOY, Lat, Lon] (18-D) → Linear Projection → LayerNorm → GELU → 16-D Latent State Vector z.

2. Continuous Depth Decoder:
Depth tokens query continuous vertical coordinates using sinusoidal positional embeddings: PE(z, 2i) = sin(z / 10000^{2i/d})
3. Multi-Head Cross-Attention:
Surface latent states attend to depth tokens through 4 attention heads, decoding vertical heat distributions.

4. Heteroscedastic Uncertainty Head:
Dual output streams predict mean profile $\hat{T}(z)$ and log-variance $\log \sigma^2(z)$.

Physics-Informed Loss Formulation

Guaranteed gravitational stratification and vertical continuity.

The loss function balances data-driven heteroscedastic NLL with physical regularization: ℒ = ℒ_{NLL} + λ_{strat} ℒ_{strat} + λ_{smooth} ℒ_{smooth} 1. Gravitational Stratification Penalty:
In stable open-ocean conditions below the mixed layer, temperature must not invert unstably: ℒ_{strat} = (1 / K-1) ∑ max(0, ∂T / ∂z)² 2. Profile Smoothness Regularization:
Penalizes non-physical vertical oscillations: ℒ_{smooth} = (1 / K-2) ∑ (∂²T / ∂z²)²
🛡️ Scientific Guarantee: Without the stratification penalty $\mathcal{L}_{strat}$, purely data-driven networks occasionally predict unphysical density inversions. AquaSphere guarantees dynamically stable profiles.
